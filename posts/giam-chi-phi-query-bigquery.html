Giảm chi phí query BigQuery: 4 cách đơn giản

2026-11-23 | Tag: BigQuery, SQL, Tối ưu chi phí

BigQuery tính phí theo lượng dữ liệu mà query quét. Vì vậy, quét ít hơn nghĩa là chi phí thấp hơn.

1. Chọn cột thay vì SELECT *

BigQuery lưu dữ liệu theo cột. Chỉ chọn cột cần dùng thì lượng dữ liệu quét sẽ giảm đáng kể.

2. Dùng partition

Chia bảng theo ngày (hoặc theo một cột phù hợp). Khi lọc đúng cột partition, BigQuery chỉ đọc các phân vùng liên quan.

3. Dùng cluster

Cluster sắp xếp dữ liệu theo các cột hay lọc hoặc join. Cách này giúp bỏ qua những khối dữ liệu không cần thiết.

4. Xem bytes trước khi chạy

Giao diện BigQuery hiển thị ước tính dung lượng sẽ xử lý ở góc trên bên phải trình soạn thảo. Có thể dùng thêm chế độ dry run để kiểm tra mà không chạy thật.

Ví dụ (chỉ để minh họa)

Tên bảng và cột dưới đây là giả định.

-- Tốn kém: quét toàn bộ cột
SELECT * FROM my_dataset.orders;

-- Tiết kiệm hơn: chọn cột + lọc theo partition
SELECT order_id, amount
FROM my_dataset.orders
WHERE order_date BETWEEN '2024-01-01' AND '2024-01-07';
