Giảm chi phí query BigQuery: 4 thói quen nên có

Đăng ngày: NGAY_DANG | Tag: bigquery, toi-uu-chi-phi, sql

BigQuery tính phí chủ yếu theo lượng dữ liệu mà query quét. Vì vậy, quét ít hơn nghĩa là chi phí thấp hơn.

1. Chọn cột thay vì SELECT *

BigQuery lưu dữ liệu theo cột. Chỉ chọn những cột cần dùng để tránh phải đọc cả bảng.

2. Dùng partition

Chia bảng theo ngày (hoặc theo khoảng thời gian). Khi lọc đúng cột partition, BigQuery chỉ quét các partition liên quan.

3. Dùng cluster

Cluster sắp xếp dữ liệu theo một số cột hay lọc, ví dụ mã khách hàng hoặc mã đơn. Cách này giúp giảm lượng dữ liệu phải đọc.

4. Xem bytes trước khi chạy

Giao diện BigQuery hiển thị ước tính dung lượng sẽ xử lý trước khi chạy. Hãy xem con số này, hoặc dùng chế độ dry run, để kiểm tra trước khi thực thi.

Ví dụ SQL (chỉ để minh họa)

-- Minh họa: tên bảng và cột là giả định
SELECT order_id, amount
FROM my_dataset.orders
WHERE order_date BETWEEN '2024-01-01' AND '2024-01-07'
  AND customer_id = 'C001';

Query này chọn đúng hai cột, lọc theo cột partition (order_date) và cột cluster (customer_id). Giả định: bảng được partition theo order_date và cluster theo customer_id.

Kết luận: chọn đúng cột, lọc theo partition, tận dụng cluster và luôn kiểm tra bytes ước tính.
